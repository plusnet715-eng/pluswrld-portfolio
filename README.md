# Pluswrld Portfolio

A multi-page portfolio website and Sanity Studio for Pluswrld.

## Structure
- web/ — Next.js App Router website. Vercel root directory: web.
- studio/ — Sanity Studio source. Vercel root directory: studio.

## Content
The website reads the public Sanity dataset a8mywjme/production. The Studio source reuses that exact project and dataset. Existing documents and assets are preserved.

The public project grid includes only confirmed client work with a live website. Le Drip remains excluded pending scope confirmation. The Reviews page uses existing Fiverr feedback; further review entries can be added later.

## Brand
- Pluswrld
- Build · Automate · Grow
- EMMPIRISISSO — Knowledge comes from sensory ideas.
- Green gradient, charcoal and white
- Acumin Pro headings (Adobe Fonts kit) and Work Sans body

## Local development
For the website, run npm install and npm run dev from the web directory.
For the CMS, run npm install and npm run dev from the studio directory.

The public website requires no private read token. Sanity Studio requires a Sanity account with editing access.
